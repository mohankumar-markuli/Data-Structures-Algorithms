### Bubble Sort

```
Given an array of n elements, the task is to sort the array in ascending order using the Bubble Sort algorithm.
```
Example 1
```   
    Input: nums = [64, 34, 25, 12, 22, 11, 90]
    Output: [11, 12, 22, 25, 34, 64, 90]
```
Constraints: 
```
Best Case: O(n) — when the array is already sorted (with optimization using a swap flag).
Average Case: O(n²) — elements are in random order.
Worst Case: O(n²) — when the array is sorted in reverse order.

```
